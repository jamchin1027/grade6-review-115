# 複習小島｜115 學年度六上

給國小六年級學生使用的靜態複習網站。直接由 GitHub Pages 提供，不需安裝、登入或後端服務。每個孩子的答題紀錄只存在自己瀏覽器的 localStorage；不會上傳至 GitHub。進度頁提供 JSON 備份及匯入。

## 課程範圍

- 南一國語六上第 1–6 課：在天晴了的時候、珍珠鳥、客至、贏得喝采的輸家、哇！原來如此、登月先鋒。
- 康軒自然六上第 1–2 單元：探索天氣的變化、水溶液。
- 南一社會六上第 1–2 單元：日治時期臺灣的發展與變遷、邁向民主的社會。
- 翰林英文 Here We Go 9 Unit 1: Where Did You Go Last Weekend?；Unit 2: What Did He Do Yesterday?。

國語第 2、6 課於 115 學年度有內容調整；重點採原創文字概述，不重製課本全文。使用時以學生手上的課本、學校授課進度為準。社會課名以南一出版社 115 上課本目錄核對。

## GitHub Pages

Repository → Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/(root)`。

首頁是 `index.html`，無 build step、框架或第三方 runtime dependency。樣式及字型設有系統字型 fallback。

## 期中試卷與刷題（2026-10-27 更新）

題庫共 511 題：國語 282、自然 65、社會 44、英文 120。包含 160 題「歷屆考點延伸・本站另編」、21 題原創概念題、210 題生字練習、120 題英文期中範圍延伸。歷屆考點延伸以公開試卷核對考點後，另寫情境、選項與解析，不標示為原卷逐字題目。

- 段考／主題參考：和順、桃子腳、東區勝利、河堤、大同區太平、內安、二林廣興、板橋莒光，共 8 所學校 9 份試卷。
- 依使用者要求移除進階競賽區、7 年慈濟菁英盃連結及期末資料夾入口，集中於本次期中複習。英文目前沒有收錄校內段考原卷。
- 重要範圍限制：舊版六上自然卷的熱單元不納入。莒光水溶液參考卷原為 108 學年度五上，清楚標出跨年級。勝利國語只採相同課文及共通語文考點；舊版社會古文明卷不採用。
- 每個延伸題附 `sourceId` 和 `sourceRef`；`bank.js` 的 `PAPERS` 記錄原卷、解答、年度及範圍。原卷只提供外部連結，未存入儲存庫。

刷題可按學科、單元、考點來源學校選題，選 10／20／40／全部題數。抽題優先選未作答題目，當未作答題不足才補入做過的題目；同回合不重複。選項隨機重排並同步對應答案。練習模式即時解析，模擬考於整回合完成後顯示解析，答題期間不更新會透露對錯的錯題徽章。答對既有錯題即從錯題寶箱移除。

沿用 `review-island-115-v1` 學習紀錄，新增 `seen` 題目 ID 紀錄；舊版本只有累積次數，無法還原所有曾答過的題目，因此新題庫的未練習統計從更新後逐題記錄。學習資料只在本機，未新增追蹤或網路傳輸。

## 英文與作答導航（2026-10-27）

使用者確認課本為 Here We Go 9，並提供 Unit 1、Unit 2 標題。18 組主題詞、句型與 c / g 拼讀範圍另對照[臺北市公開課程計畫](https://tten.tp.edu.tw/Login/Downment?grade=99&spid=7079e0b0-2865-44f9-8173-9533291684ec&subject=English)中 Here We Go 9 的六年級表格；該計畫為 114 學年度，不能宣稱是 115 課本逐頁核驗。相關教學重點也與[五常國小 114 六年級英語課程計畫](https://tten.tp.edu.tw/Login/Downment?grade=6&spid=e137d288-3af4-4f85-93f2-457ae757298e&subject=AddEnglish)比對。英文情境與題目全為本站另編，不重製課文故事或完整試卷。

- `english-data.js`：Unit 1 共 62 題、Unit 2 共 58 題；單字 36、句型 55、閱讀 21、發音辨別 8。每個選項皆有以選項文字為鍵的錯因說明，重排後仍對應正確。原形與過去式、did / didn’t、人稱、地點／活動及否定線索分開解析。
- `english.js`：看圖翻卡、裝置英文朗讀、三種句型變身工坊、發音示例、範圍／題型選擇與期中模擬考。朗讀採瀏覽器合成語音，不錄音、不自動評口說分數；不可用時有提示。
- `quiz.js`：上一題／下一題、題號跳轉、漏答提醒；回看不重新打亂選項。練習模式保留首次作答且只計一次；模擬考可修改，交卷前不更新統計、錯題或正確標記，交卷時才記錄最後答案一次。離開未交卷模擬考不計入成績。
- 四科共用「線索／錯因／方法／換你試試」解析。新錯題保存實際所選文字，以便在錯題寶箱解釋該選項；舊紀錄維持原解析。

## 驗證與維護

### 生字本（2026-10-26）

依教育部教育雲「115 學年度上學期・六年級・國語・南一版」逐課核對：第 1 課 10 字，第 2–6 課各 19 字，共 105 字。只取表格標示「生字」的項目，不把語詞列誤算為生字。來源：[第 1 課](https://pedia.cloud.edu.tw/Bookmark/TCollection?TextNameId=0102061150101)、[第 2 課](https://pedia.cloud.edu.tw/Bookmark/TCollection?TextNameId=0102061150102)、[第 3 課](https://pedia.cloud.edu.tw/Bookmark/TCollection?TextNameId=0102061150103)、[第 4 課](https://pedia.cloud.edu.tw/Bookmark/TCollection?TextNameId=0102061150104)、[第 5 課](https://pedia.cloud.edu.tw/Bookmark/TCollection?TextNameId=0102061150105)、[第 6 課](https://pedia.cloud.edu.tw/Bookmark/TCollection?TextNameId=0102061150106)。

`vocab-data.js` 保存生字、指定詞語的讀音、另編簡義、字形提醒和逐字教育百科連結。`vocab.js` 產生每字兩題，共 210 題注音／國字選擇題；多音字以題目詞語為準。這些是課本生字延伸題，不是歷屆原題。首頁、導覽列、各課內容皆有生字本入口，可按課次閱讀、選題型測驗，或六課混合練習。「遮字默寫」供孩子在紙上書寫並自行核對，沒有筆跡辨識或自動默寫評分。刷題練功房另可依題型分開練閱讀概念、注音、國字。

測試另外檢查 105 字逐課名單、每字兩題、國字題不洩漏答案、題型篩選、遮字內容和生字測驗重練。

執行 `node tests/check.mjs`：檢查 511 題唯一 ID、選項、答案、來源關聯、逐選項英文解析；重複打亂選項驗證正解；驗證未做優先、舊紀錄載入、回前題、跳題、漏答、練習不重複計分、模擬考修改與交卷只計一次、錯題錯因保存、範圍篩選與競賽移除。瀏覽器另檢查翻卡、句型工坊、題號導航、作答與解析呈現。

`bank.js` 先將舊資料轉成帶 ID 的題目，再補回各科考卷。修改題目時保留既有 ID，避免讓孩子的已作答紀錄失去對應。發佈時更新 `index.html` 的資源版本字串。
