# 複習小島｜115 學年度六上

給國小六年級學生使用的靜態複習網站。直接由 GitHub Pages 提供，不需安裝、登入或後端服務。每個孩子的答題紀錄只存在自己瀏覽器的 localStorage；不會上傳至 GitHub。進度頁提供 JSON 備份及匯入。

## 課程範圍

- 南一國語六上第 1–6 課：在天晴了的時候、珍珠鳥、客至、贏得喝采的輸家、哇！原來如此、登月先鋒。
- 康軒自然六上第 1–2 單元：探索天氣的變化、水溶液。
- 南一社會六上第 1–2 單元：日治時期臺灣的發展與變遷、邁向民主的社會。

國語第 2、6 課於 115 學年度有內容調整；重點採原創文字概述，不重製課本全文。使用時以學生手上的課本、學校授課進度為準。社會課名以南一出版社 115 上課本目錄核對。

- 公開段考試卷入口：[米蘭老師教育資訊室](https://melances.com/grade6/)。分類有南一國語、康軒自然、南一社會及不同年度的學校試卷。題庫連結只作練習參考，舊卷不保證與 115 學年度單元或臺南學校進度完全相同。

網站內互動題均為自行編寫的概念複習題，並非歷屆考題。外部試卷及答案屬原提供者或相關權利人所有，網站只提供連結。

## GitHub Pages

Repository → Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/(root)`。

首頁是 `index.html`，無 build step、框架或第三方 runtime dependency。樣式及字型設有系統字型 fallback。

## 跨校試卷與刷題（2026-10-26 更新）

題庫共 181 題：國語 72、自然 65、社會 44。新增 160 題「歷屆考點延伸・本站另編」，保留 21 題原創概念題。新增題目以公開試卷核對考點後，另寫情境、選項與解析，不標示為原卷逐字題目。

- 段考／主題參考：和順、桃子腳、東區勝利、河堤、大同區太平、內安、二林廣興、板橋莒光，共 8 所學校 9 份試卷。
- 慈濟：臺南慈濟高中官方 109–115 學年度「小六菁英盃」國語原卷及解答，共 7 年；屬競賽，並非慈濟國小六上校內段考，不計入 181 題。
- 重要範圍限制：舊版六上自然卷的熱單元不納入。莒光水溶液參考卷原為 108 學年度五上，清楚標出跨年級。勝利國語只採相同課文及共通語文考點；舊版社會古文明卷不採用。
- 每個延伸題附 `sourceId` 和 `sourceRef`；`bank.js` 的 `PAPERS` 記錄原卷、解答、年度及範圍。原卷只提供外部連結，未存入儲存庫。
- 慈濟官方目錄：https://www.tcsh.tn.edu.tw/Acad-111Camping.aspx 。校方學年度名稱不等同舉辦日期，例如 115 卷面是 2025-11-29，114 卷面是 2024-11-24。

刷題可按學科、單元、考點來源學校選題，選 10／20／40／全部題數。抽題優先選未作答題目，當未作答題不足才補入做過的題目；同回合不重複。選項隨機重排並同步對應答案。練習模式即時解析，模擬考於整回合完成後顯示解析，答題期間不更新會透露對錯的錯題徽章。答對既有錯題即從錯題寶箱移除。

沿用 `review-island-115-v1` 學習紀錄，新增 `seen` 題目 ID 紀錄；舊版本只有累積次數，無法還原所有曾答過的題目，因此新題庫的未練習統計從更新後逐題記錄。學習資料只在本機，未新增追蹤或網路傳輸。

## 驗證與維護

執行 `node tests/check.mjs`：檢查題數、唯一 ID、選項、答案、來源關聯；重複打亂選項驗證正解；驗證未做優先、不重複抽題、舊紀錄載入、模擬考隱藏解析、錯題重練及單元篩選。另在瀏覽器實際完成十題模擬考、核對結果解析及慈濟學校／年度篩選。

`bank.js` 先將舊資料轉成帶 ID 的題目，再補回各科考卷。修改題目時保留既有 ID，避免讓孩子的已作答紀錄失去對應。發佈時更新 `index.html` 的資源版本字串。
